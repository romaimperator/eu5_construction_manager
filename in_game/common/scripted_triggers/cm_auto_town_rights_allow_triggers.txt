# Generated from vanilla EU5 1.4 town_rights `allow` blocks - regenerate after a game update.

# Country trigger. Mirrors each vanilla town_rights_type `allow` block so auto-grant
# only grants a right on a location the engine would allow it on.
# Expects scope:cm_town_right (the right) and scope:target (the candidate location).
# Rights linked by vanilla `upgrades_to` additionally exclude each other, so auto-grant never
# stacks a charter and its upgraded form in one location (upgrade those through the vanilla UI).
